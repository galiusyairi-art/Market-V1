# TradeKit: כלי תומך מסחר (תוך-יומי + סווינג)

סורק שוק בזמן אמת דרך Interactive Brokers. הוא שולח התראות עם כניסה, סטופ, טייק פרופיט, יעד וגודל פוזיציה, ומודל לומד מסנן מהן את ההתראות החלשות. כל התראה נשמרת ביומן, וכל תוצאה חוזרת לאימון, כך שאיכות ההתראות משתפרת ככל שהמערכת צוברת היסטוריה.

> הכלי לא מבצע פקודות. הוא מתריע, ואתה מחליט ומבצע.

## איך זה עובד

```
 IBKR (נתונים חיים + סורקים)
        │
        ▼
 ┌──────────────┐   7 אסטרטגיות   ┌────────────────┐  הסתברות   ┌──────────────┐
 │ סורק חי      │ ───────────────▶│ מודל מטא       │ ─────────▶ │ מנוע התראות  │──▶ טלגרם / מסך / דשבורד
 │ פרה-מרקט→סגירה│                 │ (Meta-labeling)│            │ סיכון, סינון │
 └──────────────┘                  └────────────────┘            └──────┬───────┘
        ▲                                   ▲                           │
        │                                   │ אימון מחדש                ▼
 ┌──────────────┐  Triple-barrier   ┌────────────────┐  תוצאות    ┌──────────────┐
 │ מטמון ברים   │ ─────────────────▶│ בקטסט          │ ◀───────── │ יומן התראות  │
 └──────────────┘                   └────────────────┘            └──────────────┘
```

1. **אסטרטגיות** (`tradekit/strategies`) קובעות את העסקה: מה קונים, איפה נכנסים, איפה הסטופ ואיפה היעד.
2. **בקטסט** מריץ כל אסטרטגיה על ההיסטוריה ומתייג כל איתות בשיטת Triple-barrier: מה נגע קודם, היעד, הסטופ או הזמן. התוצאה נמדדת ב-R, כלומר כמה פעמים הסיכון ההתחלתי, אחרי החלקה.
3. **מודל מטא** (`meta.py`) לומד מהתוצאות האלה אילו איתותים של כל אסטרטגיה נוטים להצליח, לפי RVOL, גאפ, מיקום מול VWAP ומול הממוצעים, משטר השוק, שעה ביום ועוד. הוא מאומן ונבדק ב-walk-forward: המודל תמיד נבחן על עסקאות שקרו אחרי הנתונים שלמד מהם. הסף נבחר לפי התוחלת (R ממוצע לעסקה), לא לפי אחוז ההצלחה.
4. **לולאת הלמידה:**
   - כל התראה נכנסת ליומן (`var/journal.db`).
   - `resolve` בודק מה קרה איתה בפועל.
   - `train` מאמן מחדש על הבקטסט ועל התוצאות האמיתיות, ונותן לתוצאות האמיתיות משקל גבוה פי 3.
   - אסטרטגיה שהתוחלת שלה ב-30 ההתראות האחרונות שלילית מושתקת אוטומטית.

## האסטרטגיות

| | אסטרטגיה | מתי | בסיס |
|---|---|---|---|
| יומי | `orb` | פריצת טווח 5 הדקות הראשונות, רק ב"מניות במשחק" (RVOL ≥ 1, ‏20 העליונות ביום) | Zarattini, Barbon, Aziz (2024) |
| יומי | `vwap_pullback` | יום מגמה, פולבק ראשון ל-VWAP שמחזיק | Zarattini & Aziz (2023): מגמה מעל/מתחת ל-VWAP |
| יומי | `gap_and_go` | גאפ ≥ 4% ופריצת שיא הפרה-מרקט ב-30 הדקות הראשונות | פרקטיקה נפוצה; ייבחן בבקטסט שלך |
| סווינג | `earnings_gap` | גאפ ≥ 5% בנפח ×2 שנסגר בחצי העליון | Post-earnings drift |
| סווינג | `trend_pullback` | מגמת עלייה (50>200), פולבק ל-EMA20 ונר היפוך | מומנטום + חזרה לממוצע קצרה |
| סווינג | `base_breakout` | בסיס צר (ATR10/ATR50 < 0.8) שפורץ לשיא 50 יום, קרוב לשיא שנתי | VCP / Minervini, O'Neil |
| סווינג | `rsi2_reversion` | RSI(2) < 10 מעל ממוצע 200 | Connors |

כל הפרמטרים ניתנים לשינוי ב-`config.yaml` (מפתח `strategies`). סיכום המחקר שמאחורי הבחירות נמצא ב-[`docs/RESEARCH.md`](docs/RESEARCH.md).

## התקנה

```bash
cd trader
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp config.example.yaml config.yaml      # ערוך: פורט IBKR, גודל חשבון, סיכון לעסקה
pytest -q                               # 11 בדיקות
tradekit demo                           # כל המערכת על נתונים סינתטיים, בלי ברוקר
```

### Interactive Brokers
1. **TWS** או **IB Gateway** פתוחים. ב-Settings → API מסמנים *Enable ActiveX and Socket Clients*, ובוחרים פורט: ‏7497 לנייר, ‏7496 לחשבון אמיתי.
2. **מנויי נתונים (בערך 15$ לחודש, בתוך התקציב שלך):**
   - *US Securities Snapshot and Futures Value Bundle*: ‏10$, ומתבטל מעל 30$ עמלות בחודש.
   - *US Equity and Options Add-On Streaming Bundle*: ‏4.50$ בערך.
   - לבדיקות בלי מנוי: `market_data_type: 3` (נתונים מושהים).
3. מומלץ להתחיל בחשבון נייר (paper) ולהריץ את הכלי כמה שבועות לפני שסומכים עליו.

### התראות לטלגרם (אופציונלי)
יוצרים בוט אצל @BotFather, שולחים לו הודעה, ולוקחים את ה-chat id. אחר כך:
```bash
export TRADEKIT_TELEGRAM_TOKEN=...   TRADEKIT_TELEGRAM_CHAT=...
```

## שימוש יומיומי

```bash
tradekit fetch --daily "3 Y" --intraday-symbols NVDA,TSLA,AMD,PLTR --intraday-days 60   # פעם אחת: בונה היסטוריה
tradekit backtest                    # תוצאות כל אסטרטגיה ב-R, לפי הנתונים שלך
tradekit train                       # מאמן את מודל המטא ובודק את בריאות האסטרטגיות
tradekit live                        # להפעיל לפני 09:00 שעון ניו יורק; רץ עד אחרי הסגירה
tradekit journal --open              # ההתראות הפתוחות
tradekit mark "NVDA|orb|2026-10-12" taken --r 1.8     # מה עשית בפועל
tradekit resolve && tradekit train   # פעם בשבוע: הכלי לומד מהתוצאות
tradekit health                      # אילו אסטרטגיות עובדות עכשיו ואילו מושתקות
```

**מהלך יום של `tradekit live`:**
- **04:00–09:30:** הסורקים של IBKR (Top % Gainers, Hot by Volume) בונים רשימה של עד 40 "מניות במשחק".
- **09:30–16:00:** כל נר של דקה מריץ את 3 האסטרטגיות התוך-יומיות. איתות חדש עובר דרך מודל המטא, בריאות האסטרטגיה ומגבלות הסיכון, ואז נשלחת התראה.
- **16:10:** סריקת סווינג על כל רשימת המניות, ואחריה עדכון היומן.

## חשוב לדעת
- **הבקטסט הוא הבסיס לכל החלטה.** לפני שמפעילים אסטרטגיה, להריץ `tradekit backtest` על הנתונים שלך. אסטרטגיה עם תוחלת שלילית מושתקת אוטומטית.
- **התוצאות של `tradekit demo` הן על נתונים סינתטיים.** הן מוכיחות שהצנרת עובדת, לא שיש אדג'.
- **החלקה ועמלות** מוגדרות ב-`costs.slippage_bps` (ברירת מחדל 5 נקודות בסיס לכל צד). בפריצות יומיות עם סטופ צמוד הן אוכלות חלק גדול מה-R, אז לא כדאי להוריד אותן כדי ש"ייראה טוב".
- **מגבלות IBKR:** כ-60 בקשות היסטוריה ל-10 דקות לברים קטנים, ועד כ-100 קווי דאטה במקביל. לכן הסורק עוקב אחרי עד 40 מניות, והורדת היסטוריית דקות איטית בפעם הראשונה (אחר כך הכול במטמון).
- הכלי הוא כלי תומך החלטה. הוא לא ייעוץ השקעות ולא מבטיח רווח.
