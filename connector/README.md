# מחבר Finnhub ל-Claude

שרת MCP קטן שרץ ב-Cloudflare Workers, בחינם. הוא נותן ל-Claude ולדשבורד מחירים בזמן אמת, חדשות, תאריכי דוחות ומצב שוק מ-Finnhub.

## הכלים
| כלי | מה מחזיר |
|---|---|
| `get_quotes` | מחיר לפי סשן (פרה-מרקט, מסחר רגיל או אפטר-מרקט), % שינוי מול הסגירה הקודמת, טווח הפרה-מרקט, טווח היום וסגירה קודמת (עד 30 סימולים) |
| `get_daily` | סטטיסטיקה יומית משנה של סגירות שהושלמו: ממוצעים 20/50/150/200, ATR(14), נפח ממוצע, שיא/שפל שנתי, סגירות בסיס לשבוע/חודש/שנה, RSI ותבנית מגמה 0–7 (עד 40 סימולים, כולל ‎^VIX ו-‎^TNX) |
| `get_company_news` | כותרות אחרונות למניה |
| `get_earnings_calendar` | תאריכי דוחות קרובים |
| `get_market_status` | האם השוק פתוח, ובאיזה סשן (פרה-מרקט, רגיל או אפטר-מרקט) |

## התקנה (בלי להתקין כלום על המחשב)
1. **מפתח Finnhub:** נרשמים ב-https://finnhub.io/register, ומעתיקים את ה-API key מה-Dashboard.
2. **Cloudflare:** נרשמים בחינם ב-https://dash.cloudflare.com/sign-up.
3. בתפריט: **Workers & Pages** ← **Create** ← **Start with Hello World!** ← שם: `finnhub-mcp` ← **Deploy**.
4. **Edit code** ← מוחקים את כל הקוד ← מדביקים את התוכן של `finnhub-worker.js` ← **Deploy**.
5. חוזרים ל-Worker ← **Settings** ← **Variables and Secrets** ← **Add**. מוסיפים שני משתנים מסוג **Secret**:
   - `FINNHUB_KEY`: המפתח מ-Finnhub.
   - `ACCESS_TOKEN`: מחרוזת סודית ארוכה, שמשמשת כסיסמה בכתובת.
   
   ← **Deploy**.
6. **בדיקה:** פותחים בדפדפן `https://finnhub-mcp.<החשבון-שלך>.workers.dev/mcp/<ACCESS_TOKEN>`:
   - `Method not allowed`: הכול תקין.
   - `Server not configured`: חסר אחד מהסודות.
   - `Not found`: הטוקן בכתובת לא נכון.
7. **ב-claude.ai:** Settings ← Connectors ← **Add custom connector**. שם: `Finnhub`, וכתובת: הכתובת מסעיף 6. אחר כך מפעילים אותו בשיחה, דרך תפריט המחברים.

## מאיפה המחירים (גרסה 2)
ב-Finnhub החינמי יש רק את המסחר הרגיל. לפני 16:30 שעון ישראל הוא עדיין מחזיר את הסגירה של אתמול ואת אחוז השינוי של אתמול. לכן `get_quotes` עובד כך:
- **מקור ראשי: Yahoo Finance** (גרף דקות עם פרה-מרקט ואפטר-מרקט). כל שורה מציינת:
  - `session`: באיזה סשן השוק עכשיו.
  - `price_session`: מאיזה סשן המחיר.
  - `change_pct`: השינוי מול הסגירה הקודמת. כשעוד אין עסקאות היום הערך `null`, ולא 0.
  - `pm_high`/`pm_low`: טווח הפרה-מרקט.
  - `high`/`low`: טווח המסחר הרגיל של היום בלבד.
- **הצלבה עם Finnhub:** אם שני המקורות רחוקים זה מזה ביותר מ-0.75%, השדה `check` מקבל את הערך `mismatch`, והדשבורד מציג אזהרה.
- **אם Yahoo לא זמין:** משתמשים ב-Finnhub לבד, עם תווית ברורה ובלי מספרי פרה ואפטר. הדשבורד אומר את זה במפורש.

### גרסה 3
- נוספו `or_high`/`or_low` (טווח 5 הדקות הראשונות) ו-`vwap` ל-`get_quotes`.
- נוסף הכלי `get_daily`.
- סימולים של מדדים ב-Yahoo נתמכים, למשל ‎^VIX ו-‎^TNX.

### עדכון מגרסה קודמת
**Workers & Pages** ← `finnhub-mcp` ← **Edit code** ← מוחקים הכול ← מדביקים את `finnhub-worker.min.js` ← **Deploy**. הסודות והכתובת נשארים כמו שהם, ואין צורך לשנות משהו ב-claude.ai.

## אבטחה
- המפתח של Finnhub שמור כסוד ב-Cloudflare, והוא לא מופיע בקוד ולא בכתובת.
- השרת עונה רק לכתובות שמכילות את ה-`ACCESS_TOKEN`. לא לשתף את הכתובת.
- המסלול החינמי של Finnhub הוא לשימוש אישי בלבד, ומוגבל לכ-60 קריאות בדקה.

## בדיקות
```bash
node test.mjs            # פרוטוקול MCP וכל הכלים, מול Finnhub מדומה
node test_sessions.mjs   # פרה-מרקט, מסחר רגיל, אפטר-מרקט, סוף שבוע, נפילה ל-Finnhub, מגבלת הבקשות של Cloudflare
W=./finnhub-worker.min.js node test_sessions.mjs   # אותן בדיקות על הגרסה המכווצת
```
